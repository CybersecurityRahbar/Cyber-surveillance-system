# مواصفات مركز التحكم المروري والأمني

## 1. مفهوم الواجهة
لوحة عمليات مركزية لكاميرات متعددة، لا مجرد صفحة إحصائيات. التصميم يجمع بين VMS لعرض الفيديو ومركز عمليات لتحليل التنبيهات والتحقيق بالأحداث.

## 2. وحدات التنقل
1. **Operations Overview** — مؤشرات حركة المرور، الإنذارات الحرجة، حالة الكاميرات، مصادر الانقطاع.
2. **Live Camera Wall** — Grid متعدد الكاميرات، اختيار تخطيطات 1/4/9/16، Hotspot، تبديل المشاهد، إظهار metadata فوق الفيديو.
3. **Traffic Analytics** — العد حسب نوع المركبة والمسار والاتجاه، السرعة، كثافة المرور، طول الطوابير، أوقات الذروة.
4. **Visual Security** — المناطق المحظورة، التسلل، عبور المحيط، التسكع، التجمعات والأجسام المرشحة.
5. **Events & Alarms** — قائمة قابلة للفرز والتصفية والإقرار والإسناد والانتقال إلى المقطع.
6. **Camera Inventory** — بيانات الكاميرا وموقعها واتصالها وزاويتها ودقتها ومعدل الإطارات وآخر صورة.
7. **Calibration Studio** — صورة الكاميرا، نقاط المعايرة الأرضية، القياسات المترية، خطأ reprojection، صلاحية المعايرة، حفظ إصدار.
8. **Zones & Virtual Lines** — رسم polygons والخطوط والاتجاهات ومناطق المسارات وقواعدها فوق صورة الكاميرا.
9. **Investigation & Evidence** — timeline، المقطع قبل/بعد الحدث، snapshots، مسارات track، metadata، hash، سجل التصدير.
10. **Reports** — تقارير الحركة والسرعة والازدحام والحوادث والإنذارات وجودة الخدمة.
11. **System Health** — FPS الفعلي لكل كاميرا، dropped frames، decode latency، inference latency، queue depth، GPU/CPU/RAM، انقطاع/تجمد الصورة.
12. **Administration** — المستخدمون والأدوار والاحتفاظ والصلاحيات وتدقيق عمليات المشغلين.

## 3. Overview layout
- شريط علوي: الموقع/المنطقة، نطاق الزمن، وضع Live/Playback، البحث، حالة الخدمة.
- العمود الرئيسي: أكبر الإنذارات وأحداث اللحظة.
- جانب الكاميرات: عدد الكاميرات المتصلة/المتوقفة/المتأخرة.
- رسوم التدفق: vehicles/minute حسب lane وdirection.
- مخطط ازدحام ومناطق عالية الخطورة.
- مصفوفة الأحداث: traffic vs security مع confidence.
- لا تعرض السرعات المحسوبة من كاميرا بمعايرة غير صالحة كقيمة رسمية.

## 4. Camera Wall
- تخطيطات مرنة 1/4/9/16 وأكثر حسب موارد العميل.
- اختيار كاميرا يجعلها Hotspot بدقة أعلى.
- يمكن تثبيت كاميرات حرجة أو جعلها rotating carousel.
- overlay يبين camera ID، timestamp، FPS، حالة المعايرة، والتنبيهات.
- زر الانتقال إلى Playback حول وقت الحدث.
- لا نرسل كل الإطارات عبر API metadata؛ نفصل media delivery عن JSON events.

## 5. واجهة التحليل والتحقيق
كل Alert card يجب أن تجيب:
- ماذا حدث؟
- أي كاميرا ومكان؟
- متى بالضبط ووفق أي ساعة؟
- أي track تأثر؟
- ما القاعدة والقيم التي أدت للمطابقة؟
- ما جودة الكشف/المعايرة/التوقيت؟
- ما الإطار والمقطع الداعم؟
- هل تمت مراجعة التنبيه؟ ومن اتخذ القرار؟

Timeline يربط الأحداث مع الفيديو والـ track. العلاقات بين الكاميرات تظهر كـ candidate handoff بدرجة ثقة، لا كهوية يقينية.

## 6. Calibration Studio
- تحديد نقاط الصورة على road plane.
- إدخال الإحداثيات الأرضية بالمتر.
- معاينة Bird's-eye/BEV.
- إظهار reprojection error والـ inliers.
- رفض matrix المفردة أو المعايرة غير المستقرة.
- حفظ نسخة camera-specific وresolution-specific.
- إعادة فحص المعايرة عند تدوير الكاميرا أو تغيير الزوم أو مجال الرؤية.

## 7. تجربة الاستخدام
- واجهة داكنة عالية التباين مناسبة لغرف المراقبة.
- جداول كثيفة قابلة للفرز مع تفاصيل عند التحديد.
- لا رسوم تزينية؛ كل رسم قابل للانتقال إلى الفيديو/الأحداث التي بنت الرقم.
- تدعم العربية RTL والإنجليزية LTR على مستوى المكونات.
- تنبيهات صوتية/مرئية قابلة للتخصيص، لا تحوّل كل حركة بسيطة إلى Alarm.
- صلاحيات تفصل مشاهدة البث عن تصدير الأدلة أو إدارة الكاميرات.

## 8. غير منفذ بعد
هذه وثيقة تصميم. لا توجد حتى الآن واجهة React ولا video wall ولا map ولا camera wall متصلة. تنفذ بعد تثبيت API وبروتوكول البث وتحديد متطلبات عدد الكاميرات.

## المختبر أحادي الكاميرا

قسم مستقل لا يحتاج Camera Inventory أو كاميرا متصلة. يتيح:
- اختيار فيديو محلي وسحب/إفلات.
- معاينة الفيديو الأصلي قبل الإرسال.
- اختيار ByteTrack أو BoT-SORT أو OC-SORT أو متتبعات أخرى.
- ضبط confidence وموضع خط العد وحجم معالجة الصورة.
- رؤية الإطارات المعالجة أثناء العمل مع مربع أخضر وTrack ID والصنف والثقة ومسار الحركة.
- إظهار unique vehicle tracks وperson tracks وline crossings وprocessing FPS.
- تنزيل MP4 الناتج.

### جلسة بث حي تجريبية
- مصدر RTSP أو كاميرا موصولة بجهاز الخادم.
- جلسة محددة المدة مع زر إيقاف.
- معاينة JPEG أثناء الجلسة وحفظ MP4.
- لا يعرض API credentials أو كلمة مرور البث ضمن تفاصيل job.

### حدود المختبر
لا يعرض سرعة رسمية أو قراءة لوحة ما لم تكن هناك معايرة صالحة ونموذج plate/OCR مناسب. العد الحالي مبني على Track IDs؛ إذا فقد المتتبع الهوية أو أعاد إنشاء ID، قد يتأثر العدد. لذلك تظهر النتائج كتجربة جلسة، لا كـ ground truth.
